# MendanFlow

SESのIT面談（クライアント面談・顔合わせ）の**準備**から**結果処理**までを一元管理するアプリ。

## 解決したい課題

- 面談前の準備（案件情報の整理、想定質問、スキルシートの確認）が属人的でバラバラ
- 面談後の結果・フィードバックが記録されず、次の面談に活かせない
- 案件ごと・エンジニアごとの面談履歴が追えない

## 主な機能（予定）

### 面談準備
- 案件情報の登録（クライアント、案件概要、必須スキル、面談日時）
- 想定質問リストの作成・テンプレート化
- 準備チェックリスト

### 面談結果の処理
- 面談結果の記録（合否、フィードバック、質問された内容）
- 振り返りと次回への改善メモ
- 面談履歴の一覧・検索

### 経歴書の読み込み
- 経歴書ファイル（PDF / テキスト / 画像）をアップロードすると、Claudeが分析して経歴メモと深掘りポイントを自動生成
- 記載の不整合（スキル年数と在籍期間のズレなど）や曖昧な記述を面接前に洗い出せる

### AI壁打ち（質問を一緒に考える）
- 候補者の経歴メモ・深掘りポイントを元に、Claudeが候補者固有の質問を提案
- 「もっとチーム面を聞きたい」など方向性を伝えて対話的にリストを練り上げる
- 提案は「採用」で質問リストへ、「スキップ」で却下

## 技術スタック

- [Next.js](https://nextjs.org)（App Router / TypeScript）
- Tailwind CSS
- [Claude Agent SDK](https://platform.claude.com/docs/en/agent-sdk)（AI壁打ち機能）

## 開発

```bash
npm install
npm run dev
```

http://localhost:3000 で起動します。

AI壁打ち機能は、このマシンのClaude Codeのログイン情報（Pro/Max契約）を使います。APIキーは不要ですが、`claude` CLIでログイン済みである必要があります。ログインしていなくてもAI壁打ち以外の機能は動作します。
